# HayDay_Database_Project
Навчальний проєкт: Проєктування БД для гри Hay Day. Проєкт було зупинено на етапі автоматичного завантаження даних з Excel, щоб змінити фокус на глибше вивчення чистого SQL на простіших таблицях.

UPD: Цей проєкт було відновлено пізніше з метою заповнення БД даними та продовження практики SQL, після ознайомлення з базовими темами SQL на іншому проєкті.
